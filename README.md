# Alkarizmia — Site vitrine coachs sportifs

Page unique de présentation des services de création de sites web pour coachs sportifs indépendants et petites salles (Bruxelles et alentours).

**Stack :** React + Vite. Aucun backend. Déployable sur Vercel.

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Étapes détaillées à l’étape finale du projet.
